XIL-AC · herramienta local

Revisión de privacidad antes de enviar

Esta página busca señales de posibles datos sensibles en un texto, directamente en este navegador.

Importante: el resultado no certifica que el texto sea seguro. Si contiene información de consultantes, no lo envíes a la API remota de XIL-AC. Esta herramienta solo ayuda a detectar algunas señales explícitas.

1. Revisá el texto localmente

Pegá el texto en el campo. La herramienta no tiene función de envío, no consulta servicios externos y no guarda el contenido.

2. Cómo interpretar el resultado

  • Señales detectadas: no continúes con el envío. Revisá el texto y mantené cerrada la API remota para sesiones.
  • No se detectaron señales: eso no significa que el texto esté anonimizado ni que sea seguro. Puede contener identidades indirectas o detalles reconocibles.
  • Antes de compartir: eliminá nombres, contactos, documentos, direcciones, fechas precisas y detalles únicos que permitan reconocer a alguien.

La inspección ocurre en el navegador de este dispositivo. El contenido no se escribe en almacenamiento web ni se transmite por esta página. Esto no protege frente a dispositivos comprometidos, extensiones del navegador, sincronización del portapapeles u otros programas externos. Detector heurístico: puede dar falsos positivos y falsos negativos.
